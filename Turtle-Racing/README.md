# Turtle Racing 🐢

A graphical multi-colored turtle race built with Python's `turtle` module (*100 Days of Code*). Place your bet, watch the turtles race across a custom finish line, and see if your color wins!

## Features
* **Interactive Betting:** GUI pop-up (`textinput`) to place your color bet.
* **Custom Finish Line:** Checkered finish line drawn dynamically with stamps.
* **OOP State Management:** Multiple `Turtle` instances generated in a loop with distinct coordinates and colors.
* **Random Movement:** Randomized step distances for unpredictable race outcomes.

## How to Run
1. Ensure **Python 3** is installed.
2. Run the script:
```bash
python main.py

## How to Play
Enter your chosen turtle color in the pop-up prompt.

Watch the race unfold on the 800x600 canvas.

Check the terminal to see if your bet won!

Secret Auction 🏆

A command-line Python application that handles a blind auction where multiple users can cast secret bids. This project is part of the 100 Days of Code: The Complete Python Pro Bootcamp.

The program collects names and bid amounts silently, clearing the screen between turns to hide previous bids, before calculating and announcing the highest bidder at the end.

✨ Features
Secret Bidding Mechanism: Collects names and bid values securely while hiding them from subsequent users.
Dynamic Screen Clearing: Simulates screen clearing by printing empty lines to keep previous bids confidential.
Highest Bidder Calculation: Automatically scans the gathered data to determine the absolute winner and their final bid value.
Zero Dependencies: Fully self-contained inside a single file with embedded ASCII art—no external package installations required!

🚀 How to Run
Make sure you have Python 3 installed on your computer.
Clone or download this repository.
Open your terminal or VS Code terminal in the project directory.
Run the script using the following command:
python main.py

🎮 How to Play
Input your name when prompted by the terminal.
Enter the numeric dollar amount you are willing to bid.
Type yes if there is another bidder waiting to take their turn, or enter no to conclude the auction.
Watch the screen clear to keep the auction secret for the next player.
View the final results instantly to see who won the item and at what price!

🛠️ Built With
Python 3 - Pure standard library implementation.
ASCII Art - Embedded cleanly for styled terminal visual output.
